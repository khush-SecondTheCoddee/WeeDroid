Welcome to WeeDroid OS

WeeDroid is tuned for familiar desktop computing on 2 GB RAM machines.

Start menu

Use the bottom-left WeeDroid menu to launch apps, settings, and power options.

Performance tips

Keep browser tabs low, use Mousepad or Geany for light editing, and prefer one large app at a time on 2 GB RAM.

System tools

Synaptic installs software, GParted manages disks, Timeshift creates restore snapshots, and Gufw controls the firewall.
